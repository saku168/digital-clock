# Digital Clock

A small digital clock built with **HTML, CSS and vanilla JavaScript**. It displays the current local time and date in your browser.

## Features
- Updates the time every second.
- Displays the current date in French.
- Responsive layout for different screen sizes.

## Run locally
1. Clone or download this repository.
2. Open `index.html` in your browser.

No installation or build tools are required.

## Files
- `index.html` — page structure
- `style.css` — layout and appearance
- `script.js` — clock and date updates

## What this project practises
Working with JavaScript dates, intervals, and updating page content.
